# Task 005 Oracle Test: ROS1 → ROS2 Offboard Control Translation

## Overview

This directory contains **oracle tests** designed to validate the semantic equivalence between the original ROS1 PX4 offboard control logic and the translated ROS2 C++ code generated by an LLM.  

The oracle tests **do not execute the code**, but instead use **pattern matching** (regex and string search) to verify that critical ROS1 concepts have been correctly migrated to ROS2, and that the translation preserves PX4 offboard control semantics.

---

##Source Code:

`https://github.com/ros/ros_tutorials`

---

## Purpose

The tests ensure that:

- ROS1 control loops (`while(ros::ok()) { ... rate.sleep(); }`) are correctly migrated to **ROS2 timer-based execution**.
- PX4 offboard mode **heartbeat semantics** are preserved (periodic setpoint streaming).
- ROS2 **clock-based timestamps** are used instead of wall-clock time.
- PX4 **command ordering** is maintained.
- QoS semantics for PX4 → ROS2 message bridges are explicitly configured.
- ROS1 APIs are **not leaked** into the translated ROS2 code.

---

## Test Cases Overview

| Test Case | Design Reason | Expected Outcome to Pass |
|-----------|---------------|--------------------------|
| `test_ros1_control_loop_migrated_to_ros2_timer()` | Ensure ROS1 `while(ros::ok()) { ... rate.sleep(); }` is migrated to ROS2 timer-based model for periodic execution. | Code contains `create_.*timer` call; continuous control logic scheduled periodically. |
| `test_control_logic_inside_timer_callback()` | PX4 offboard logic must execute **periodically** inside the timer callback, not only once in constructor or main. | Timer callback defined with `[this]() {...}`; `publish()` calls inside timer callback; constructor does not directly call `publish()`. |
| `test_offboard_heartbeat_semantics_preserved()` | PX4 offboard mode requires continuous streaming of setpoints; missing periodic publishing breaks offboard mode. | Code publishes to `trajectory_setpoint_publisher_` and `offboard_control_mode_publisher_` periodically (inside timer callback). |
| `test_ros_time_semantics_preserved()` | ROS1 `ros::Time::now()` must map to ROS2 clock; wall-clock time (`std::chrono`) is not acceptable for PX4 timestamps. | `get_clock()->now()` used; forbidden wall-clock libraries (`std::chrono`, `system_clock`, `steady_clock`) are not present. |
| `test_px4_command_order_semantics()` | PX4 offboard logic requires strict command order: stream setpoints → switch to OFFBOARD → arm vehicle. | `trajectory_setpoint_publisher_` called before `publish_vehicle_command`; `arm()` called after switching to OFFBOARD. |
| `test_px4_qos_semantics_explicit()` | PX4 uORB → ROS2 bridge requires explicit QoS; default QoS may drop messages or break offboard behavior. | Code uses `rclcpp::QoS` explicitly for publishers/subscribers. |
| `test_no_ros1_api_leakage()` | Translation must not retain ROS1 APIs (ros::Publisher, ros::Rate, ROS_INFO, etc.) in ROS2 code. | No forbidden ROS1 APIs appear in the translated code. |
